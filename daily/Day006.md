# Day 006｜Merge Intervals（合併區間）
日期：2026-10-13｜難度：Medium｜建議時間：25～35 分鐘

## 題目
給定一組整數閉區間 `int[][] intervals`，每筆資料都是 `[start, end]`。
合併所有重疊的區間，回傳依照起點升冪排序的**新陣列**。
注意共同端點也算重疊：`[1,4]` + `[4,5]` → `[1,5]`，
但 `[1,2]` 和 `[3,4]` 不重疊。

```csharp
Day006MergeIntervals.Merge([[1,3], [2,6], [8,10], [15,18]]);
// [[1,6], [8,10], [15,18]]

Day006MergeIntervals.Merge([[1,4], [4,5]]); // [[1,5]]
Day006MergeIntervals.Merge([[1,10], [2,3]]); // [[1,10]]
Day006MergeIntervals.Merge([]);              // []
```

## 輸入契約
- 外層為 `null`：擲出 `ArgumentNullException`，參數名稱 `intervals`。
- 任一內層為 `null`、長度不是 2，或 `start > end`：擲出 `ArgumentException`。
- 空輸入應回傳空陣列。
- 不可修改輸入外層陣列或內層資料；輸出內層陣列也不能與輸入共用。
- 必須處理重複、包含、連鎖重疊、負數與極端整數。

## 挑戰
- 主題：Sorting + Greedy（排序 + 貪婪法）。
- 目標時間複雜度：**O(n log n)**。
- 目標額外空間複雜度：**O(n)**。
- 提示：讓可能重疊的區間彼此相鄰，並維護已合併區間的最右端點。
- 排序比較器不要用相減，極端 `int` 值相減可能溢位。

# Day 003 解法回顧（請先完成題目）

本題要找目標值第一次出現的位置，而非任一個符合位置。一般的 `Array.BinarySearch` 在有重複元素時，不能直接保證回傳第一個。

維護半開區間 `[left, right)`，找出第一個大於或等於 target 的索引：小於 target 的位置連同左半部可以排除；大於或等於 target 時繼續搜尋左半部。區間為空後再檢查值是否相等。

每次將搜尋範圍縮小約一半，時間 O(log n)，額外空間 O(1)。使用 `left + (right - left) / 2` 計算中點，避免兩個索引直接相加造成溢位。輸入保證已排序，解答不應重新排序或增加 O(n) 的排序驗證。

常見錯誤：找到相同數值就返回、right 的開閉邊界混用、迴圈邊界沒有推進、以兩數相減比較 int 大小而溢位、對空陣列讀取索引 0。

測試包括 24 組基本案例與 5 個額外測試，涵蓋 int 極值、輸入不變性、100,000 個元素與 250 組固定種子隨機案例。大資料測試通過不能單獨證明 O(log n)，仍需檢視程式迴圈。

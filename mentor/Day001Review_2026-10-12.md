## 可讀性與較佳 C# 寫法

`memery` 可改名為 `firstIndexByValue`，清楚表達字典用途。方法註解的 `i > j` 與規格及實際回傳相反，應描述輸出索引依遞增順序排列。

可使用 .NET 8 支援的 `ArgumentNullException.ThrowIfNull(numbers)` 簡化參數檢查。字典的 key 可以保留為 `int`，只在互補值運算使用 `long`，超出 int 範圍時跳過查找；這樣增加一次範圍檢查，換取更小的 key 型別，實際速度仍需量測。保留目前 `Dictionary<long, int>` 的寫法也正確，且控制流程較簡單。

```csharp
public static int[] Solve(int[] numbers, int target)
{
    ArgumentNullException.ThrowIfNull(numbers);
    var firstIndexByValue = new Dictionary<int, int>();

    for (var currentIndex = 0; currentIndex < numbers.Length; currentIndex++)
    {
        var complement = (long)target - numbers[currentIndex];
        if (complement is >= int.MinValue and <= int.MaxValue &&
            firstIndexByValue.TryGetValue((int)complement, out var earlierIndex))
        {
            return [earlierIndex, currentIndex];
        }

        firstIndexByValue.TryAdd(numbers[currentIndex], currentIndex);
    }

    return [];
}
```

字典未預先配置整個陣列長度，避免很早找到答案時也配置 O(n) 容量。若通常需要掃描完整陣列，可量測指定初始容量是否有幫助。

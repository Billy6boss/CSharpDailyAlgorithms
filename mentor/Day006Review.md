# Day 006｜Merge Intervals：解題後檢討

先完成你的實作和 xUnit 測試，再閱讀 `Day006MergeIntervalsReference.cs`。

核心策略：按 `start` 排序（記得不要修改輸入），依序維護目前合併區間。當下一個區間的 `start <= end` 時，以 `Math.Max(end, nextEnd)` 更新終點；否則輸出上一段並開始新的一段，最後再輸出剩餘區間。

常見錯誤：忘了合併共同端點、被完全包含的區間讓 `end` 變小、排序修改輸入陣列、排序比較器用 `a - b` 而溢位、回傳原始內層陣列。

**最佳化目標**：時間 **O(n log n)**（排序 + 一次掃描）、額外空間 **O(n)**（保留輸入、輸出與排序快照）。

# Day 005 解法回顧（建議完成題目後再閱讀）

Kadane 演算法維護兩個值：`endingHere` 是「必須在目前位置結尾」的最大總和，`best` 是到目前為止所有位置的最佳答案。

每遇到一個元素，選擇從該元素重新開始，或延伸前一段區間。這個決策只需要前一個 `endingHere`，因此時間 O(n)、額外空間 O(1)。暴力枚舉區間並累加需要 O(n²) 時間。

非空陣列必須至少選一個元素，因此不能把 `best` 初始化為 0：全負數輸入 `[-5, -2, -9]` 的答案是 -2。空陣列則依本題契約回傳 0。

累加值使用 `long`，例如 `[int.MaxValue, int.MaxValue]` 的答案是 4,294,967,294。即使陣列含有 100,000 個合法 `int`，總和也可安全放入 `long`。

測試包含 32 組具名參數案例及 7 個額外測試；其中一個測試以固定種子生成 1,000 組輸入，與 O(n²) 的獨立暴力 oracle 比對。另有 100,000 元素測試、輸入不變性及重複呼叫測試。大輸入測試有助於發現低效率解法，但測試通過本身不能證明 O(n)，仍須閱讀實作。

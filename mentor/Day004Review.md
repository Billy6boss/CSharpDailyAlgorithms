# Day 004 解法回顧（請先完成題目）

以 left、right 維護一段不含重複字元的滑動視窗。字典記錄每個 char 最近出現的索引；遇到目前視窗內已存在的字元時，將 left 移到前次位置的下一格。

left 只能向右移動。例如 `abba` 的第二個 b 會將 left 移到 2；最後的 a 前次位置為 0，已在視窗外，所以不能把 left 移回 1。可用 `previousIndex >= left` 判斷，或以 `Math.Max(left, previousIndex + 1)` 維護此不變量。

平均時間 O(n)，額外空間 O(min(n, k))，k 為輸入中可能的 char 種類數。C# char 為 UTF-16 code unit，上限 65,536 種；本題以 char 為單位，不以 Unicode scalar value 或使用者看到的一個文字單位計算。因此 `😀😀` 的答案是 2。若需求改成按 Rune 或文字元素計算，題目契約及測試都必須調整。

不要枚舉所有 Substring 再 Distinct，這會重複掃描並配置字串。參考實作只需要原字串、索引與字典，不產生子字串。

測試包含 29 組基本案例與 5 個額外測試，涵蓋大小寫、中文、空字元、surrogate、100,000 字元輸入，以及 400 組固定種子隨機案例對照獨立 O(n²) 暴力解法。
